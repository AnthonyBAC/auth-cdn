# Theme Review Guide

Review each MVP screen against these checks:

- Background, surface, primary text, secondary text, and emphasis colors map to documented tokens.
- Typography uses `GRIFTER` for headings or `Inter` for interface content with documented fallbacks.
- Spacing, radius, and elevation use the token reference before introducing one-off values.
- Text and controls meet WCAG 2.2 AA contrast.
- Focus, disabled, warning, error, and destructive states are visible without relying on color alone.
- Desktop and mobile layouts keep text readable and controls reachable without overlap.

Screens covered by this guide: register, login, workspace list, board view, card editing, workspace settings, members, and location context.
