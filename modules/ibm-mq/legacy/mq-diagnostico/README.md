Diagnósticos históricos del transporte nativo IBM MQ, conservados para referencia.
No forman parte del servidor Next.js ni del transporte REST. Las pruebas que
requieren `/tmp`, `/bin/sh` y `/proc` se ejecutan solo fuera de Windows.
Para reproducir manualmente los diagnósticos nativos se necesita `ibmmq@2.1.9`
en un entorno independiente con el cliente nativo y certificados correspondientes.
El procedimiento cloud vigente está en `modules/ibm-mq/docs/mensajeria-mq.md`.
